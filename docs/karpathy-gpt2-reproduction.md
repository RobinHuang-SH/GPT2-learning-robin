\# Karpathy GPT-2 From Scratch：学习与复现计划



\## 1. 项目目标



跟随 Andrej Karpathy 的《Let's reproduce GPT-2 (124M)》，从模型结构到训练过程，理解并复现 GPT-2 的核心机制。



本项目分为两个阶段：



\- 本地完成模型实现、前向传播、损失计算、小规模训练和文本生成。

\- 在资源允许的情况下，进一步复现大规模预训练，并记录训练指标和评测结果。



本项目首先训练的是基础语言模型，不是经过指令微调的 ChatGPT。



\## 2. 参考资料



\- 视频教程：https://www.youtube.com/watch?v=l8pRSuU81PU

\- 官方代码：https://github.com/karpathy/build-nanogpt

\- 后续工程化训练参考：https://github.com/karpathy/nanoGPT



优先阅读官方代码的 Git 提交历史，观察模型是如何从简单实现逐步演化到完整 GPT-2 的。



\## 3. 学习路线



\### 第一阶段：理解并实现 GPT-2



重点学习 Tokenizer、Token Embedding、Position Embedding、Causal Self-Attention、MLP、Residual Connection、LayerNorm、Logits 和文本生成。



验收标准：能够解释模型输入输出的形状，独立完成一次前向传播，并理解自回归生成过程。



\### 第二阶段：完成训练流程



学习训练数据的构造、Next Token Prediction、Cross Entropy Loss、梯度计算、反向传播、AdamW 优化器和梯度累积。



验收标准：能够使用小规模数据完成训练，观察训练损失变化，并生成可读的文本片段。



\### 第三阶段：优化训练速度



学习 GPU 计算、混合精度、Tensor Cores、Flash Attention、`torch.compile`、学习率预热、余弦衰减、权重衰减和梯度裁剪。



验收标准：记录优化前后的单步训练时间、吞吐量和显存占用，并说明每项优化的作用。



\### 第四阶段：数据与完整预训练



理解 FineWeb-Edu 数据、GPT-2 Tokenizer、数据分片、训练集与验证集划分，以及大规模训练所需的计算资源。



先用可控的小数据集完成实验，再评估是否运行完整数据准备和预训练。



验收标准：保存训练配置、数据来源、验证损失、训练日志和最终模型评测结果。



\### 第五阶段：评测与总结



对比训练前后生成文本的变化，观察验证损失，并参考官方的 HellaSwag 评测流程。



验收标准：形成一份能够复现的实验报告，清楚区分实际测量结果和预期结果。

\## 5. 实验记录规范



每次实验至少记录以下内容：

\- Git Commit

\- 模型配置与训练超参数

\- GPU 型号、显存占用和单步耗时

\- 训练损失与验证损失

所有实验结果应与对应的代码版本和配置关联。不要覆盖已有实验结果。
